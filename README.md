## Setup

- **OS:** Arch Linux
- **Compositor:** Sway
- **Bar:** Waybar
- **Launcher:** Wofi
- **Terminal:** Kitty
- **Shell:** Bash
- **File Manager:** Nautilus
- **GTK Theme:** Breeze Dark
- **Font:** Departure Mono
- **System Info:** Fastfetch

## Dotfiles
